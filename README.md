# ProConSheet

ProConSheet is a lightweight pros-and-cons worksheet built with React, TypeScript, and Vite. It helps you compare four perspectives in one screen:

- Pros of doing
- Cons of doing
- Pros of not doing
- Cons of not doing

## Features

- Four-quadrant decision sheet
- Chinese and English interface toggle
- Local persistence with `localStorage`
- Markdown export with copy and download support
- Keyboard-friendly item editing

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
pnpm preview
```
